## Добро пожаловать!

Этот курс научит вас работе с технологиями виртуализации и контейнеризации на Linux: **KVM**, **LXC/LXD** и **Docker**.

## ⏱️ Быстрый старт за 10 минут

### Шаг 1: Проверка системы

```bash
# Проверка виртуализации
grep -E '(vmx|svm)' /proc/cpuinfo

# Проверка версии ядра (минимум 4.18)
uname -r

# Свободное место (минимум 50GB)
df -h
```

### Шаг 2: Выбор модуля

Выберите с чего начать:

#### 🖥️ **Option A: KVM (Аппаратная виртуализация)**
Если вам нужно:
- Запускать полноценные виртуальные машины
- Использовать разные ОС (Windows, Linux, BSD)
- Максимальная изоляция

```bash
cd Lab-01-KVM
sudo ./scripts/setup-host.sh
./scripts/deploy.sh
```

#### 📦 **Option B: LXC (Системные контейнеры)**
Если вам нужно:
- Легковесные Linux системы
- Быстрый запуск (<5 сек)
- Разработка/тестирование

```bash
cd Lab-02-LXC
sudo ./scripts/init-lxd.sh
./scripts/deploy.sh
```

#### 🐳 **Option C: Docker (Контейнеры приложений)**
Если вам нужно:
- Контейнеризация приложений
- Microservices архитектура
- Быстрая разработка

```bash
cd Lab-03-Docker
./scripts/build-all.sh
./scripts/start.sh
```

### Шаг 3: Проверка работы

```bash
# KVM
virsh list --all

# LXC
lxc list

# Docker
docker ps
```

## ❓ Часто задаваемые вопросы

### Q: Можно ли запустить на Windows/macOS?
**A:** Да, через WSL2 (Windows) или виртуальную машину. Но лучше использовать нативный Linux.

### Q: Нужны ли права root?
**A:** Для KVM и LXC — да. Для Docker — пользователь должен быть в группе `docker`.

### Q: Какой модуль самый важный?
**A:** Для современной разработки — **Docker**. Для системного администрирования — **KVM**.

### Q: Сколько времени займет курс?
**A:** ~13-15 часов для полного прохождения всех модулей.

### Q: Где получить помощь?
**A:** Проверьте раздел Troubleshooting в README каждого модуля.

## 🐛 Быстрое решение проблем

### Проблема: KVM не работает
```bash
# Проверка
kvm-ok

# Решение
sudo modprobe kvm kvm_intel  # или kvm_amd
```

### Проблема: Docker permission denied
```bash
# Решение
sudo usermod -aG docker $USER
newgrp docker
```

### Проблема: LXD не инициализирован
```bash
# Решение
sudo lxd init --auto
```
